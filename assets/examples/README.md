# Примеры файлов для импорта лотов

Эта папка содержит примеры файлов для импорта лотов в FunPay Customizer.

## Файлы

### lots_example.json
Пример файла в JSON формате с массивом лотов. Используйте этот формат для структурированных данных.

**Преимущества:**
- Легко генерируется программно
- Поддержка вложенных структур
- Строгая типизация

**Использование:**
1. Скопируйте файл или создайте свой на его основе
2. Заполните данные ваших лотов
3. Сохраните с расширением `.json`
4. Загрузите через вкладку "Лоты" в настройках расширения

### lots_example.txt
Пример файла в текстовом формате. Используйте этот формат для простого ручного создания.

**Преимущества:**
- Простота создания и редактирования
- Можно создать в любом текстовом редакторе
- Читаемый человеком формат

**Использование:**
1. Скопируйте файл или создайте свой
2. Заполните данные лотов
3. Разделяйте лоты с помощью `---`
4. Сохраните с расширением `.txt`
5. Загрузите через вкладку "Лоты" в настройках расширения

## Формат данных

### Обязательные поля
- `name` - Название лота (строка, до 200 символов)
- `price` - Цена (число, положительное)

### Необязательные поля
- `description` - Описание (строка, до 5000 символов)
- `currency` - Валюта (строка, по умолчанию: RUB)
- `category` - Категория (строка)
- `subcategory` - Подкатегория (строка)
- `gameId` - ID игры (строка)
- `serverId` - ID сервера (строка)
- `stock` - Количество (число, неотрицательное, по умолчанию: 1)

## Рекомендации

1. **Начните с малого**: Попробуйте импортировать 1-2 лота для тестирования
2. **Проверяйте данные**: Включите валидацию перед импортом
3. **Используйте задержки**: Установите задержку минимум 2 секунды между пакетами
4. **Резервное копирование**: Сохраните копию файла перед импортом

## Создание собственных файлов

### JSON
```json
[
  {
    "name": "Ваш лот",
    "description": "Описание",
    "price": 1000,
    "currency": "RUB",
    "stock": 10
  }
]
```

### TXT
```
name: Ваш лот
description: Описание
price: 1000
currency: RUB
stock: 10
---
```
