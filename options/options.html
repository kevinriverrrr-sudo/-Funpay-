Настройте внешний API для перевода текста на странице

ℹ️ О переводчике

Эта функция позволяет переводить текст на страницах FunPay, используя внешние сервисы перевода (LibreTranslate или DeepL). Ваши API-ключи хранятся локально в браузере и не передаются третьим лицам.

Для LibreTranslate: URL сервера (например, https://libretranslate.com)
Для LibreTranslate: может не требоваться на публичных серверах
Для DeepL: обязателен, получите на deepl.com/pro-api
При включении, на страницах с товарами появятся кнопки для быстрого перевода названий и описаний
🔒 Приватность и безопасность
  • API-ключи хранятся локально в chrome.storage.local
  • Переводы кэшируются в рамках сессии для снижения нагрузки на API
  • Текст отправляется только на указанный вами сервер
  • При отсутствии настроек API функция перевода не работает
💡 Как использовать
  • Выделите текст на странице, чтобы увидеть кнопку быстрого перевода
  • Используйте контекстное меню (правый клик) для перевода выделенного текста
  • Включите автоперевод товаров для добавления кнопок перевода к названиям и описаниям
  • Переводы сохраняются в кэше до перезагрузки браузера
