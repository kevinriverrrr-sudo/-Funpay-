## 🚀 Быстрый старт

### Первый запуск

1. После установки расширения нажмите на его иконку на панели инструментов
2. Вы увидите popup окно с основными настройками
3. Выберите тему из выпадающего списка
4. Нажмите "Применить"
5. Обновите страницу FunPay, если необходимо

### Базовая настройка

**Минимальная конфигурация** для начала работы:
- Выберите тему (рекомендуется "Тёмная" для работы в вечернее время)
- Оставьте шрифт по умолчанию
- Нажмите "Применить"

## 🎨 Смена тем

### Предустановленные темы

Расширение включает несколько готовых тем:

#### 1. **По умолчанию**
- Стандартное оформление FunPay
- Без изменений цветовой схемы

#### 2. **Тёмная тема**
- Тёмный фон для комфортной работы в вечернее время
- Снижает нагрузку на глаза
- Рекомендуется для длительной работы

#### 3. **Светлая тема**
- Чистая светлая палитра
- Идеальна для работы при ярком освещении

#### 4. **Синяя тема**
- Холодные синие тона
- Профессиональный вид
- Подходит для бизнес-окружения

#### 5. **Фиолетовая тема**
- Творческая фиолетовая палитра
- Уникальный стиль
- Приятна для длительного просмотра

### Как применить тему

**Через Popup:**
1. Нажмите на иконку расширения
2. В выпадающем списке "Тема оформления" выберите нужную
3. Нажмите "Применить"

**Через настройки:**
1. Нажмите "Расширенные настройки"
2. Перейдите на вкладку "Темы"
3. Нажмите "Выбрать" под нужной темой
4. Нажмите "Сохранить и применить"

### Автоматическое применение

Тема применяется автоматически при:
- Переходе на новые страницы FunPay
- Обновлении страницы
- Открытии новых вкладок с FunPay

## 🔤 Настройка шрифтов

### Доступные шрифты

Расширение предлагает популярные шрифты от Google Fonts:

- **Roboto** - современный, геометрический
- **Open Sans** - дружелюбный, универсальный
- **Lato** - полукруглый, теплый
- **Montserrat** - элегантный, геометрический
- **PT Sans** - российский, универсальный
- **Ubuntu** - гуманистичный
- И другие...

### Как изменить шрифт

**Через Popup:**
1. Откройте popup расширения
2. Выберите шрифт из списка "Шрифт"
3. Настройте размер ползунком (12-20px)
4. Нажмите "Применить"

**Через настройки:**
1. Откройте расширенные настройки
2. Перейдите на вкладку "Шрифты"
3. Выберите шрифт
4. Настройте размер
5. Просмотрите результат в блоке "Предпросмотр"
6. Нажмите "Сохранить и применить"

### Рекомендации по шрифтам

- **Для чтения**: Open Sans, Lato, PT Sans
- **Для современного вида**: Roboto, Poppins, Inter
- **Для элегантности**: Montserrat, Raleway
- **Для креативности**: Nunito, Ubuntu

### Размер шрифта

- **12-13px**: Компактный вид, больше информации на экране
- **14px**: Стандартный размер (по умолчанию)
- **16-18px**: Увеличенный размер для комфортного чтения
- **19-20px**: Максимальный размер для людей с проблемами зрения

## 🖼️ Загрузка обложек

### Поддерживаемые форматы

- **JPEG/JPG**: Фотографии, изображения
- **PNG**: Изображения с прозрачностью
- **GIF**: Анимированные изображения

**Максимальный размер**: 5 МБ

### Как загрузить обложку

1. Откройте popup или настройки
2. Нажмите "Загрузить изображение"
3. Выберите файл с компьютера
4. Настройте позиционирование и масштабирование
5. Нажмите "Применить"

### Настройки отображения

#### Позиционирование
- **По центру**: Центрирует изображение
- **Сверху**: Выравнивание по верхнему краю
- **Снизу**: Выравнивание по нижнему краю
- **Слева/Справа**: Боковое выравнивание
- **Углы**: Выравнивание по углам

#### Масштабирование
- **Заполнить (Cover)**: Заполняет весь экран, может обрезать края
- **Вместить (Contain)**: Вмещает изображение полностью
- **Оригинальный размер**: Показывает в исходном размере
- **Растянуть**: Растягивает на весь экран

### Рекомендации

- Используйте изображения с разрешением минимум 1920x1080
- Для фонов лучше подходят абстрактные или размытые изображения
- Яркие изображения могут мешать чтению текста
- Изображение отображается с прозрачностью 30% для читаемости

### Удаление обложки

1. Откройте popup или настройки
2. Нажмите "Удалить обложку" (кнопка с крестиком)
3. Нажмите "Применить"

## 🎨 Создание своей темы

### Пошаговое руководство

1. Откройте расширенные настройки
2. Перейдите на вкладку "Своя тема"
3. Настройте каждый цвет:

#### Основные цвета

- **Основной фон**: Главный фоновый цвет страницы
- **Вторичный фон**: Фон карточек, панелей
- **Третичный фон**: Фон элементов форм
- **Основной текст**: Цвет основного текста
- **Вторичный текст**: Цвет подсказок, мелкого текста
- **Цвет границ**: Цвет рамок элементов
- **Цвет ссылок**: Цвет кликабельных элементов
- **Ссылки при наведении**: Цвет ссылок при наведении мыши

#### Советы по подбору цветов

1. **Контрастность**: Обеспечьте достаточный контраст между фоном и текстом
2. **Гармония**: Используйте цвета из одной палитры
3. **Акценты**: Ссылки должны выделяться на фоне
4. **Тестирование**: Проверяйте читаемость на разных элементах

### Предпросмотр

В настройках есть блок предпросмотра, который показывает, как будут выглядеть элементы с выбранными цветами.

### Сохранение

1. Настройте все цвета
2. Нажмите "Сохранить свою тему"
3. Тема сохранится и станет доступна как "Пользовательская"
4. Нажмите "Сохранить и применить" для применения к сайту

## 📦 Импорт лотов

Расширение поддерживает автоматический импорт лотов из файлов для быстрого размещения на FunPay.

### Поддерживаемые форматы

Расширение поддерживает два формата файлов:

#### JSON формат

```json
[
  {
    "name": "Название лота",
    "description": "Описание лота",
    "price": 100,
    "currency": "RUB",
    "category": "gaming",
    "subcategory": "accounts",
    "gameId": "game_id",
    "serverId": "server_id",
    "stock": 10
  },
  {
    "name": "Второй лот",
    "description": "Описание второго лота",
    "price": 200,
    "currency": "RUB",
    "stock": 5
  }
]
```

#### TXT формат

```
name: Название лота
description: Описание лота
price: 100
currency: RUB
category: gaming
subcategory: accounts
gameId: game_id
serverId: server_id
stock: 10
---
name: Второй лот
description: Описание второго лота
price: 200
currency: RUB
stock: 5
---
```

**Важно**: Разделитель между лотами в TXT формате - три дефиса `---`

### Обязательные поля

- **name**: Название лота (до 200 символов)
- **price**: Цена (положительное число)

### Необязательные поля

- **description**: Описание (до 5000 символов)
- **currency**: Валюта (по умолчанию: RUB)
- **stock**: Количество (по умолчанию: 1)
- **category**: Категория товара
- **subcategory**: Подкатегория
- **gameId**: ID игры
- **serverId**: ID сервера

### Как импортировать лоты

#### Шаг 1: Подготовка файла

1. Создайте файл в формате JSON или TXT
2. Заполните данные лотов согласно формату
3. Проверьте обязательные поля
4. Сохраните файл (максимум 10 МБ)

#### Шаг 2: Загрузка файла

1. Откройте расширенные настройки
2. Перейдите на вкладку "Лоты"
3. Нажмите "Выбрать файл с лотами"
4. Выберите подготовленный файл
5. Дождитесь сообщения о загрузке

#### Шаг 3: Валидация (опционально)

При включенной валидации система проверит:
- Наличие обязательных полей
- Корректность типов данных
- Длину текстовых полей
- Корректность числовых значений

Результаты валидации отобразятся на странице с указанием ошибок и предупреждений.

#### Шаг 4: Настройка импорта

**Размер пакета** (1-20 лотов):
- Количество лотов для одновременной обработки
- Меньше значение = медленнее, но безопаснее
- Рекомендуется: 5 лотов

**Задержка** (1-10 секунд):
- Пауза между пакетами лотов
- Защита от антиспам-систем FunPay
- Рекомендуется: 2-3 секунды

**Валидировать перед импортом**:
- Проверяет данные перед отправкой
- Рекомендуется: включено

**Проверять каждый лот**:
- Показывает окно для проверки данных перед заполнением формы
- Позволяет редактировать данные
- Рекомендуется: включено для первого импорта

#### Шаг 5: Запуск импорта

1. Откройте страницу создания/редактирования лота на FunPay
2. Вернитесь в настройки расширения
3. Нажмите "Начать импорт"
4. Следите за прогрессом в окне импорта

### Режим проверки

При включенном режиме "Проверять каждый лот":

1. Для каждого лота откроется окно с данными
2. Вы можете отредактировать любые поля
3. Нажмите "Применить" для заполнения формы FunPay
4. Или "Пропустить" для пропуска лота

### Автоматический режим

При выключенном режиме проверки:

1. Данные автоматически заполняются в форму
2. Вы видите уведомление о результате
3. Необходимо вручную нажать "Опубликовать" на FunPay
4. Следующий лот обрабатывается после задержки

### Ограничения и особенности

#### Ограничения FunPay

- **Антиспам**: FunPay может заблокировать слишком частые действия
- **Лимиты**: Есть лимит на количество лотов в час/день
- **Проверка**: Некоторые категории требуют ручной проверки

#### Технические ограничения

- **Структура DOM**: Если FunPay изменит структуру страницы, импорт может не работать
- **Поддерживаемые поля**: Заполняются только основные поля формы
- **Одна вкладка**: Импорт работает только с одной открытой вкладкой FunPay

### Рекомендации по безопасности

1. **Начните с малого**: Протестируйте на 1-2 лотах
2. **Используйте задержки**: Не устанавливайте минимальные значения
3. **Проверяйте лоты**: Включите режим проверки для первого импорта
4. **Следите за лимитами**: Не превышайте разумное количество лотов
5. **Делайте перерывы**: Импортируйте партиями с перерывами

### Отмена импорта

1. Нажмите "Отменить импорт" в окне прогресса
2. Текущий лот будет обработан
3. Следующие лоты будут пропущены

### Хранение настроек

Настройки импорта (размер пакета, задержка, валидация) сохраняются автоматически и будут использованы при следующем импорте.

### Примеры использования

#### Пример 1: Импорт игровых аккаунтов

```json

  {

    "description": "Аккаунт с высоким рейтингом, много скинов",
    "price": 5000,
    "currency": "RUB",
    "category": "gaming",
    "gameId": "dota2",
    "stock": 1
  }
```

#### Пример 2: Массовый импорт игровой валюты

```

price: 500
currency: RUB
stock: 100

description: Быстрая доставка на любой сервер
price: 2000

stock: 50

serverId: eu-blackrock
```

### Экспорт лотов

Для создания файла импорта вы можете:
1. Вручную создать файл в текстовом редакторе
2. Использовать Excel/Google Sheets и экспортировать в JSON
3. Использовать внешние инструменты экспорта лотов

### Ручное тестирование QA

Перед массовым импортом рекомендуется:

1. **Проверка формата**:
   - Создайте тестовый файл с 1 лотом
   - Проверьте корректность парсинга

2. **Проверка валидации**:
   - Создайте лот с ошибками
   - Убедитесь, что валидация их находит

3. **Проверка заполнения**:
   - Запустите импорт 1 лота
   - Проверьте, что все поля заполнились корректно

4. **Проверка батчинга**:
   - Импортируйте 5-10 лотов
   - Проверьте работу задержек

5. **Проверка отмены**:
   - Начните импорт
   - Отмените его
   - Убедитесь, что процесс остановился

## 💡 Советы и рекомендации

### Для комфортной работы

1. **Используйте тёмную тему вечером** - снижает нагрузку на глаза
2. **Увеличьте шрифт** - если работаете долго
3. **Выбирайте неяркие обложки** - чтобы не мешали чтению
4. **Сохраняйте несколько тем** - для разного времени суток

### Производительность

1. **Большие изображения** могут замедлить загрузку
2. **Анимированные GIF** потребляют больше ресурсов
3. **Частая смена настроек** требует перезагрузки страницы

### Доступность

1. **Проверяйте контрастность** между фоном и текстом
2. **Используйте читаемые шрифты** для основного текста
3. **Избегайте слишком ярких цветов**

## 🔧 Решение проблем

### Тема не применяется

1. Обновите страницу FunPay
2. Проверьте, что расширение включено
3. Откройте консоль браузера (F12) и проверьте наличие ошибок
4. Переустановите расширение

### Шрифт не меняется

1. Проверьте интернет-соединение (шрифты загружаются с Google Fonts)
2. Очистите кэш браузера
3. Попробуйте другой шрифт

### Обложка не загружается

1. Проверьте размер файла (максимум 5 МБ)
2. Проверьте формат файла (JPG, PNG, GIF)
3. Попробуйте другое изображение

### Настройки не сохраняются

1. Проверьте, что у расширения есть разрешение на хранение данных
2. Проверьте свободное место в хранилище браузера
3. Попробуйте сбросить настройки

### Страница выглядит сломанной

1. Нажмите "Сбросить" в popup
2. Выберите тему "По умолчанию"
3. Удалите обложку
4. Если проблема сохраняется, отключите расширение

### Импорт лотов не работает

1. **Файл не загружается**:
   - Проверьте формат файла (TXT или JSON)
   - Проверьте размер файла (максимум 10 МБ)
   - Проверьте синтаксис JSON

2. **Валидация показывает ошибки**:
   - Проверьте обязательные поля (name, price)
   - Проверьте типы данных (price и stock должны быть числами)
   - Исправьте ошибки в файле

3. **Поля не заполняются**:
   - Убедитесь, что открыта страница создания лота на FunPay
   - Проверьте, что FunPay не изменил структуру страницы
   - Попробуйте режим проверки для диагностики

4. **Импорт останавливается**:
   - Проверьте, не заблокировал ли FunPay запросы
   - Увеличьте задержку между пакетами
   - Уменьшите размер пакета

5. **Ошибка "Откройте вкладку FunPay"**:
   - Откройте хотя бы одну вкладку с FunPay
   - Обновите страницу FunPay
   - Проверьте, что расширение активно на этой странице
