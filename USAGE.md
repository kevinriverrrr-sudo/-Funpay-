## 🚀 Быстрый старт

### Первый запуск

1. После установки расширения нажмите на его иконку на панели инструментов
2. Вы увидите popup окно с основными настройками
3. Выберите тему из выпадающего списка
4. Нажмите "Применить"
5. Обновите страницу FunPay, если необходимо

### Базовая настройка

**Минимальная конфигурация** для начала работы:
- Выберите тему (рекомендуется "Тёмная" для работы в вечернее время)
- Оставьте шрифт по умолчанию
- Нажмите "Применить"

## 🎨 Смена тем

### Предустановленные темы

Расширение включает несколько готовых тем:

#### 1. **По умолчанию**
- Стандартное оформление FunPay
- Без изменений цветовой схемы

#### 2. **Тёмная тема**
- Тёмный фон для комфортной работы в вечернее время
- Снижает нагрузку на глаза
- Рекомендуется для длительной работы

#### 3. **Светлая тема**
- Чистая светлая палитра
- Идеальна для работы при ярком освещении

#### 4. **Синяя тема**
- Холодные синие тона
- Профессиональный вид
- Подходит для бизнес-окружения

#### 5. **Фиолетовая тема**
- Творческая фиолетовая палитра
- Уникальный стиль
- Приятна для длительного просмотра

### Как применить тему

**Через Popup:**
1. Нажмите на иконку расширения
2. В выпадающем списке "Тема оформления" выберите нужную
3. Нажмите "Применить"

**Через настройки:**
1. Нажмите "Расширенные настройки"
2. Перейдите на вкладку "Темы"
3. Нажмите "Выбрать" под нужной темой
4. Нажмите "Сохранить и применить"

### Автоматическое применение

Тема применяется автоматически при:
- Переходе на новые страницы FunPay
- Обновлении страницы
- Открытии новых вкладок с FunPay

## 🔤 Настройка шрифтов

### Доступные шрифты

Расширение предлагает популярные шрифты от Google Fonts:

- **Roboto** - современный, геометрический
- **Open Sans** - дружелюбный, универсальный
- **Lato** - полукруглый, теплый
- **Montserrat** - элегантный, геометрический
- **PT Sans** - российский, универсальный
- **Ubuntu** - гуманистичный
- И другие...

### Как изменить шрифт

**Через Popup:**
1. Откройте popup расширения
2. Выберите шрифт из списка "Шрифт"
3. Настройте размер ползунком (12-20px)
4. Нажмите "Применить"

**Через настройки:**
1. Откройте расширенные настройки
2. Перейдите на вкладку "Шрифты"
3. Выберите шрифт
4. Настройте размер
5. Просмотрите результат в блоке "Предпросмотр"
6. Нажмите "Сохранить и применить"

### Рекомендации по шрифтам

- **Для чтения**: Open Sans, Lato, PT Sans
- **Для современного вида**: Roboto, Poppins, Inter
- **Для элегантности**: Montserrat, Raleway
- **Для креативности**: Nunito, Ubuntu

### Размер шрифта

- **12-13px**: Компактный вид, больше информации на экране
- **14px**: Стандартный размер (по умолчанию)
- **16-18px**: Увеличенный размер для комфортного чтения
- **19-20px**: Максимальный размер для людей с проблемами зрения

## 🖼️ Загрузка обложек

### Поддерживаемые форматы

- **JPEG/JPG**: Фотографии, изображения
- **PNG**: Изображения с прозрачностью
- **GIF**: Анимированные изображения

**Максимальный размер**: 5 МБ

### Как загрузить обложку

1. Откройте popup или настройки
2. Нажмите "Загрузить изображение"
3. Выберите файл с компьютера
4. Настройте позиционирование и масштабирование
5. Нажмите "Применить"

### Настройки отображения

#### Позиционирование
- **По центру**: Центрирует изображение
- **Сверху**: Выравнивание по верхнему краю
- **Снизу**: Выравнивание по нижнему краю
- **Слева/Справа**: Боковое выравнивание
- **Углы**: Выравнивание по углам

#### Масштабирование
- **Заполнить (Cover)**: Заполняет весь экран, может обрезать края
- **Вместить (Contain)**: Вмещает изображение полностью
- **Оригинальный размер**: Показывает в исходном размере
- **Растянуть**: Растягивает на весь экран

### Рекомендации

- Используйте изображения с разрешением минимум 1920x1080
- Для фонов лучше подходят абстрактные или размытые изображения
- Яркие изображения могут мешать чтению текста
- Изображение отображается с прозрачностью 30% для читаемости

### Удаление обложки

1. Откройте popup или настройки
2. Нажмите "Удалить обложку" (кнопка с крестиком)
3. Нажмите "Применить"

## 🎨 Создание своей темы

### Пошаговое руководство

1. Откройте расширенные настройки
2. Перейдите на вкладку "Своя тема"
3. Настройте каждый цвет:

#### Основные цвета

- **Основной фон**: Главный фоновый цвет страницы
- **Вторичный фон**: Фон карточек, панелей
- **Третичный фон**: Фон элементов форм
- **Основной текст**: Цвет основного текста
- **Вторичный текст**: Цвет подсказок, мелкого текста
- **Цвет границ**: Цвет рамок элементов
- **Цвет ссылок**: Цвет кликабельных элементов
- **Ссылки при наведении**: Цвет ссылок при наведении мыши

#### Советы по подбору цветов

1. **Контрастность**: Обеспечьте достаточный контраст между фоном и текстом
2. **Гармония**: Используйте цвета из одной палитры
3. **Акценты**: Ссылки должны выделяться на фоне
4. **Тестирование**: Проверяйте читаемость на разных элементах

### Предпросмотр

В настройках есть блок предпросмотра, который показывает, как будут выглядеть элементы с выбранными цветами.

### Сохранение

1. Настройте все цвета
2. Нажмите "Сохранить свою тему"
3. Тема сохранится и станет доступна как "Пользовательская"
4. Нажмите "Сохранить и применить" для применения к сайту

## 📥 Экспорт лотов

Расширение позволяет экспортировать информацию о лотах с FunPay в удобных форматах для дальнейшего анализа.

### Доступные форматы

1. **JSON (структурированный)**
   - Полная информация о каждом лоте
   - Метаданные экспорта
   - Легко обрабатывается программно
   - Подходит для интеграции с другими системами

2. **TXT (текстовый)**
   - Читаемый текстовый формат
   - Удобен для просмотра и печати
   - Включает заголовки и разделители

### Как экспортировать лоты

#### Способ 1: Через popup

1. Откройте страницу FunPay с лотами (любая страница с предложениями)
2. Нажмите на иконку расширения
3. В разделе "Экспорт лотов" выберите формат (JSON или TXT)
4. Нажмите кнопку "📥 Экспортировать лоты"
5. Файл автоматически загрузится в папку загрузок браузера

#### Способ 2: Через кнопку на странице

1. Откройте страницу FunPay с лотами
2. В правом нижнем углу появится кнопка "📥 Экспорт"
3. Нажмите на неё
4. Выберите формат экспорта в появившемся диалоге
5. Нажмите "Экспортировать"
6. Дождитесь завершения процесса

### Какая информация экспортируется

Для каждого лота собирается:

- **ID лота**: Уникальный идентификатор
- **Название**: Описание предложения
- **Цена**: Стоимость лота
- **Валюта**: RUB, USD, EUR и др.
- **Продавец**: Имя продавца
- **Статус продавца**: online/offline
- **Доступность**: available/unavailable
- **Временная метка**: Время создания/обновления
- **URL**: Прямая ссылка на лот

### Метаданные экспорта

В файл также включается:

- Дата и время экспорта
- URL страницы
- Название раздела
- Информация об аккаунте
- Общее количество лотов
- Версия формата

### Пример JSON экспорта

```json
{
  "metadata": {
    "exportDate": "2024-01-15T10:30:00.000Z",
    "url": "https://funpay.com/chips/123/",
    "sectionName": "Игровая валюта",
    "totalLots": 50
  },
  "lots": [
    {
      "id": "12345",
      "title": "1000 золотых монет",
      "price": "100.50",
      "currency": "RUB",
      "seller": "Username",
      "sellerStatus": "online",
      "availability": "available",
      "url": "https://funpay.com/lot/12345"
    }
  ]
}
```

### Пример TXT экспорта

```
================================================================================
FUNPAY LOTS EXPORT
================================================================================
Export Date: 15.01.2024, 10:30:00
Section: Игровая валюта
Total Lots: 50
================================================================================

Lot #1
--------------------------------------------------------------------------------
ID: 12345
Title: 1000 золотых монет
Price: 100.50 RUB
Seller: Username
Status: online
Availability: available
URL: https://funpay.com/lot/12345
```

### Ограничения и особенности

1. **Видимые лоты**: Экспортируются только лоты, загруженные на странице
2. **Ленивая загрузка**: Прокрутите страницу вниз, чтобы загрузить больше лотов
3. **Пагинация**: Для экспорта всех лотов нужно загрузить все страницы
4. **Структура DOM**: Работает с текущей структурой FunPay (может потребовать обновления при изменении сайта)

### Решение проблем с экспортом

#### Кнопка экспорта не появляется

1. Убедитесь, что вы на странице с лотами
2. Обновите страницу
3. Проверьте, что расширение включено

#### Лоты не найдены

1. Убедитесь, что на странице есть лоты
2. Дождитесь полной загрузки страницы
3. Прокрутите страницу для загрузки лотов

#### Ошибка "Структура страницы не поддерживается"

1. Возможно, FunPay изменил структуру страницы
2. Проверьте обновления расширения
3. Сообщите о проблеме разработчику

#### Файл не загружается

1. Проверьте разрешения браузера для загрузок
2. Проверьте свободное место на диске
3. Попробуйте другой формат экспорта

### Использование экспортированных данных

#### Для JSON:
- Импорт в Excel/Google Sheets
- Обработка в Python/JavaScript
- Интеграция с аналитическими системами
- Создание баз данных

#### Для TXT:
- Просмотр в текстовом редакторе
- Печать отчетов
- Архивирование информации
- Быстрый обзор данных

## 💡 Советы и рекомендации

### Для комфортной работы

1. **Используйте тёмную тему вечером** - снижает нагрузку на глаза
2. **Увеличьте шрифт** - если работаете долго
3. **Выбирайте неяркие обложки** - чтобы не мешали чтению
4. **Сохраняйте несколько тем** - для разного времени суток

### Производительность

1. **Большие изображения** могут замедлить загрузку
2. **Анимированные GIF** потребляют больше ресурсов
3. **Частая смена настроек** требует перезагрузки страницы

### Доступность

1. **Проверяйте контрастность** между фоном и текстом
2. **Используйте читаемые шрифты** для основного текста
3. **Избегайте слишком ярких цветов**

## 🔧 Решение проблем

### Тема не применяется

1. Обновите страницу FunPay
2. Проверьте, что расширение включено
3. Откройте консоль браузера (F12) и проверьте наличие ошибок
4. Переустановите расширение

### Шрифт не меняется

1. Проверьте интернет-соединение (шрифты загружаются с Google Fonts)
2. Очистите кэш браузера
3. Попробуйте другой шрифт

### Обложка не загружается

1. Проверьте размер файла (максимум 5 МБ)
2. Проверьте формат файла (JPG, PNG, GIF)
3. Попробуйте другое изображение

### Настройки не сохраняются

1. Проверьте, что у расширения есть разрешение на хранение данных
2. Проверьте свободное место в хранилище браузера
3. Попробуйте сбросить настройки

### Страница выглядит сломанной

1. Нажмите "Сбросить" в popup
2. Выберите тему "По умолчанию"
3. Удалите обложку
4. Если проблема сохраняется, отключите расширение
