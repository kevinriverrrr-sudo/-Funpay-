## Chrome / Chromium

### Установка из исходников (режим разработчика)

1. **Скачайте расширение**
   ```bash
   git clone https://github.com/yourusername/funpay-customizer.git
   cd funpay-customizer
   ```
   
   Или скачайте ZIP-архив и распакуйте его.

2. **Откройте страницу расширений**
   - Введите в адресной строке: `chrome://extensions/`
   - Или через меню: `⋮` → `Расширения` → `Управление расширениями`

3. **Включите режим разработчика**
   - В правом верхнем углу найдите переключатель "Режим разработчика"
   - Включите его

4. **Загрузите расширение**
   - Нажмите кнопку "Загрузить распакованное расширение"
   - Выберите папку с расширением
   - Нажмите "Выбрать папку"

5. **Готово!**
   - Расширение установлено
   - Иконка появится на панели инструментов
   - При необходимости закрепите иконку

### Установка из .crx файла

1. Скачайте файл `funpay-customizer.crx`
2. Откройте `chrome://extensions/`
3. Перетащите .crx файл в окно браузера
4. Подтвердите установку

## Mozilla Firefox

### Установка временного расширения

⚠️ **Внимание**: В Firefox расширения в режиме разработчика устанавливаются как "временные" и удаляются при закрытии браузера.

1. **Скачайте расширение** (см. инструкции для Chrome)

2. **Откройте страницу отладки**
   - Введите в адресной строке: `about:debugging#/runtime/this-firefox`
   - Или через меню: `☰` → `Другие инструменты` → `Инструменты браузера`

3. **Загрузите временное дополнение**
   - Нажмите "Загрузить временное дополнение..."
   - Перейдите в папку расширения
   - Выберите файл `manifest.json`
   - Нажмите "Открыть"

4. **Готово!**
   - Расширение установлено до закрытия браузера

### Установка постоянного расширения (.xpi)

Для постоянной установки необходимо:
1. Подписать расширение в Mozilla
2. Опубликовать в Firefox Add-ons
3. Или использовать Developer Edition / Nightly с отключенной проверкой подписей

## 🔄 Обновление расширения

### Для установленного из исходников

1. **Скачайте новую версию**
   ```bash
   cd funpay-customizer
   git pull origin main
   ```

2. **Обновите в браузере**
   - Откройте страницу расширений
   - Нажмите кнопку "Обновить" (⟳) на карточке расширения
   - Или нажмите "Обновить расширения" вверху страницы

3. **Проверьте версию**
   - Откройте popup расширения
   - Версия указана внизу страницы настроек

## 🗑️ Удаление расширения

### Chrome / Edge / Opera / Brave

1. Откройте страницу расширений
2. Найдите "FunPay Customizer"
3. Нажмите "Удалить"
4. Подтвердите удаление

### Firefox

1. Откройте `about:addons`
2. Найдите "FunPay Customizer"
3. Нажмите `⋯` → "Удалить"
4. Подтвердите удаление

## ❓ Часто задаваемые вопросы

### Почему расширение не работает?

1. Убедитесь, что вы находитесь на сайте FunPay.com
2. Обновите страницу после установки/изменения настроек
3. Проверьте, что расширение включено

### Можно ли установить из магазина?

На данный момент расширение доступно только для установки из исходников.
В будущем планируется публикация в официальных магазинах.

### Безопасно ли устанавливать из исходников?

Да, вы можете просмотреть весь исходный код перед установкой.
Расширение не собирает и не передает никакие данные.

### Нужно ли переустанавливать после перезапуска браузера?

- **Chrome/Edge/Opera/Brave**: Нет, расширение сохраняется
- **Firefox**: Да, временные расширения удаляются при закрытии

### Как сохранить настройки?

Настройки сохраняются автоматически в локальном хранилище браузера.
При переустановке расширения настройки сохраняются.
