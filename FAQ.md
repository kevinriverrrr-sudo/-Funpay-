## Общие вопросы

### Что такое FunPay Customizer?

FunPay Customizer - это браузерное расширение, которое позволяет кастомизировать внешний вид сайта FunPay.com. Вы можете менять темы оформления, шрифты, добавлять фоновые изображения и создавать свои собственные цветовые схемы.

### Для каких браузеров доступно расширение?

Расширение поддерживает:
- Google Chrome (версия 88+)
- Microsoft Edge (версия 88+)
- Opera (версия 74+)
- Brave (последние версии)
- Mozilla Firefox (версия 109+, с некоторыми ограничениями)

### Это официальное расширение FunPay?

Нет, это независимый проект с открытым исходным кодом, созданный энтузиастами для улучшения пользовательского опыта на FunPay.com.

### Бесплатно ли расширение?

Да, расширение полностью бесплатное и с открытым исходным кодом (лицензия MIT).

### Можно ли использовать расширение на других сайтах?

Нет, расширение работает только на сайте FunPay.com и его поддоменах по соображениям безопасности.

## Установка и настройка

### Как установить расширение?

Подробные инструкции по установке для каждого браузера находятся в файле [INSTALL.md](INSTALL.md).

Кратко:
1. Скачайте или клонируйте репозиторий
2. Откройте страницу расширений в браузере
3. Включите режим разработчика
4. Загрузите распакованное расширение

### Почему нужно включать режим разработчика?

Расширение пока не опубликовано в официальных магазинах (Chrome Web Store, Firefox Add-ons), поэтому его можно установить только в режиме разработчика.

### Будет ли расширение в Chrome Web Store?

Да, планируется публикация в официальных магазинах расширений в будущем.

### Нужно ли переустанавливать расширение после перезапуска браузера?

- **Chrome, Edge, Opera, Brave**: Нет, расширение остается установленным
- **Firefox**: Да, временные расширения удаляются при закрытии браузера

### Как обновить расширение?

1. Скачайте новую версию
2. Откройте страницу расширений
3. Нажмите кнопку обновления на карточке расширения

Подробнее в [INSTALL.md](INSTALL.md#обновление-расширения).

## Использование функций

### Как изменить тему?

1. Нажмите на иконку расширения
2. Выберите тему из списка
3. Нажмите "Применить"

Или откройте расширенные настройки для большего выбора тем.

### Можно ли создать свою тему?

Да! 
1. Откройте расширенные настройки
2. Перейдите на вкладку "Своя тема"
3. Настройте цвета с помощью палитр
4. Нажмите "Сохранить свою тему"

### Как изменить шрифт?

1. Откройте popup расширения
2. Выберите шрифт из списка
3. Настройте размер ползунком
4. Нажмите "Применить"

### Какой формат изображений поддерживается для обложки?

Поддерживаются форматы:
- JPEG/JPG
- PNG
- GIF (включая анимированные)

Максимальный размер файла: 5 МБ

### Как удалить фоновое изображение?

1. Откройте popup или настройки
2. Нажмите кнопку "Удалить" на превью изображения (крестик)
3. Нажмите "Применить"

### Сохраняются ли настройки?

Да, все настройки автоматически сохраняются в локальном хранилище браузера и сохраняются даже после перезапуска.

### Можно ли экспортировать/импортировать настройки?

В текущей версии (1.0.0) эта функция не реализована, но планируется в будущих обновлениях.

### Применяются ли настройки автоматически?

После нажатия кнопки "Применить" настройки применяются к:
- Текущей вкладке FunPay (мгновенно)
- Всем открытым вкладкам FunPay
- Всем новым вкладкам FunPay

## Проблемы и решения

### Тема не применяется

**Возможные причины и решения:**

1. **Страница не обновилась**
   - Решение: Обновите страницу (F5 или Ctrl+R)

2. **Расширение отключено**
   - Решение: Проверьте, что расширение включено на странице расширений

3. **Кэш браузера**
   - Решение: Очистите кэш (Ctrl+Shift+Delete)

4. **Конфликт с другими расширениями**
   - Решение: Временно отключите другие расширения для проверки

### Шрифт не меняется

**Возможные причины:**

1. **Нет интернета**
   - Шрифты загружаются с Google Fonts, требуется подключение к интернету
   
2. **Google Fonts заблокирован**
   - Если Google Fonts недоступен в вашем регионе, шрифты не загрузятся
   
3. **Кэш браузера**
   - Очистите кэш и попробуйте снова

### Обложка не загружается

**Проверьте:**

1. **Размер файла** не превышает 5 МБ
2. **Формат файла** - JPG, PNG или GIF
3. **Права доступа** к файловой системе у браузера

### Настройки не сохраняются

**Возможные причины:**

1. **Заполнено хранилище**
   - Проверьте свободное место в хранилище браузера
   
2. **Режим инкогнито**
   - В режиме инкогнито настройки могут не сохраняться
   
3. **Синхронизация отключена**
   - Включите синхронизацию в настройках браузера

### Страница выглядит сломанной

**Решения:**

1. **Сбросьте настройки**
   ```
   Popup → Кнопка "Сбросить"
   ```

2. **Выберите тему "По умолчанию"**
   
3. **Удалите обложку**

4. **Если не помогает** - переустановите расширение

### Расширение замедляет браузер

**Оптимизация:**

1. **Уменьшите размер обложки**
   - Используйте изображения меньшего размера
   
2. **Избегайте анимированных GIF**
   - Они потребляют больше ресурсов
   
3. **Отключите неиспользуемые функции**

### Ошибки в консоли

**Что делать:**

1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Скопируйте текст ошибки
4. Создайте Issue на GitHub с описанием проблемы

## Безопасность и конфиденциальность

### Безопасно ли использовать расширение?

Да! Расширение:
- Имеет открытый исходный код
- Не собирает никакие данные
- Не отправляет информацию на сторонние серверы
- Работает только на FunPay.com
- Не требует доступа к личным данным

### Какие разрешения требует расширение?

Расширение запрашивает:
- `storage` - для сохранения настроек
- `activeTab` - для работы с текущей вкладкой
- Доступ к `funpay.com` - для применения стилей

### Собирает ли расширение мои данные?

Нет! Расширение:
- Не отслеживает вашу активность
- Не собирает статистику
- Не отправляет аналитику
- Работает полностью локально

### Где хранятся мои настройки?

Настройки хранятся в локальном хранилище браузера (`chrome.storage.sync`). Данные не покидают ваше устройство.

### Может ли расширение украсть мои данные с FunPay?

Нет! Расширение:
- Не имеет доступа к вашим паролям
- Не читает содержимое страниц
- Только внедряет CSS стили для изменения внешнего вида
- Не может взаимодействовать с формами или кнопками на сайте

### Как проверить безопасность расширения?

1. Весь исходный код доступен на GitHub
2. Вы можете просмотреть все файлы перед установкой
3. Расширение не обфусцировано и легко читается
4. Нет внешних зависимостей или сторонних библиотек

### Что делать при подозрении на вредоносность?

1. Проверьте исходный код на GitHub
2. Сканируйте файлы антивирусом
3. Создайте Issue с описанием проблемы
4. Немедленно удалите расширение, если есть сомнения
