# Благодарности

Список технологий, инструментов и вдохновения для создания FunPay Customizer.

## 🛠️ Технологии

### Основные технологии

- **Chrome Extensions API** - API для создания расширений браузера
  - [Документация](https://developer.chrome.com/docs/extensions/)
  - Лицензия: Использование в соответствии с политикой Google

- **WebExtensions API** - Кросс-браузерный API
  - [Документация](https://developer.mozilla.org/docs/Mozilla/Add-ons/WebExtensions)
  - Лицензия: Open source

- **JavaScript ES6+** - Язык программирования
  - ECMAScript стандарт

- **CSS3** - Стилизация и анимации

- **HTML5** - Разметка интерфейса

### Внешние сервисы

- **Google Fonts** - Библиотека шрифтов
  - [fonts.google.com](https://fonts.google.com/)
  - Лицензия: Open Font License для большинства шрифтов
  - Используемые шрифты:
    - Roboto (Apache License 2.0)
    - Open Sans (Apache License 2.0)
    - Lato (Open Font License)
    - Montserrat (Open Font License)
    - PT Sans (Open Font License)
    - Ubuntu (Ubuntu Font License)
    - И другие...
