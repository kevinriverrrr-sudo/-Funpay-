# Changelog

Все заметные изменения в проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2024-11-03

### Добавлено

#### Основные функции
- Поддержка смены тем оформления
  - Предустановленная тёмная тема
  - Предустановленная светлая тема
  - Синяя тема
  - Фиолетовая тема
  - Возможность создания пользовательских тем
  - Сохранение настроек тем в локальном хранилище

- Кастомизация обложки
  - Загрузка собственных изображений для фона/обложки сайта
  - Поддержка форматов: JPG, PNG, GIF
  - Настройка позиционирования изображения (центр, верх, низ, углы)
  - Настройка масштабирования изображения (заполнить, вместить, оригинал)
  - Ограничение размера файла до 5 МБ

- Изменение шрифтов
  - Выбор из 12+ популярных шрифтов Google Fonts
  - Настройка размера шрифта (12-20px)
  - Применение шрифтов ко всем элементам сайта
  - Предпросмотр шрифтов в реальном времени

#### Интерфейс
- Popup окно расширения с основными настройками
  - Быстрый выбор темы
  - Быстрый выбор шрифта
  - Настройка размера шрифта
  - Загрузка обложки
  - Кнопки применения и сброса настроек

- Страница расширенных настроек
  - Вкладка "Темы" с визуальным предпросмотром
  - Вкладка "Шрифты" с детальными настройками
  - Вкладка "Обложки" с полным управлением фоном
  - Вкладка "Своя тема" для создания кастомных цветовых схем
  - Предпросмотр изменений в реальном времени

#### Техническая реализация
- Manifest V3 для совместимости с современными браузерами
- Content scripts для внедрения стилей на страницы funpay.com
- Storage API для сохранения пользовательских настроек
- CSS injection для применения кастомных стилей
- Background service worker для фоновых операций
- Обработка и хранение изображений через base64

#### Документация
- Подробный README.md с инструкциями по установке и использованию
- CONTRIBUTING.md с руководством для разработчиков
- USAGE.md с полным руководством пользователя
- LICENSE (MIT)
- CHANGELOG.md для отслеживания версий

#### Ресурсы
- Набор иконок расширения (16x16, 32x32, 48x48, 128x128)
- JSON файл с предустановленными темами
- JSON файл с доступными шрифтами
- Структура для дополнительных ресурсов

### Совместимость
- Chrome 88+
- Edge 88+
- Opera 74+
- Brave (последние версии)
- Firefox 109+ (с ограничениями Manifest V3)

### Известные ограничения
- Размер файла обложки ограничен 5 МБ
- Шрифты загружаются с Google Fonts (требуется интернет)
- Некоторые элементы сайта могут не поддерживать кастомизацию
- В Firefox могут быть небольшие отличия в работе из-за Manifest V3

## [1.1.0] - 2024-11-04

### Добавлено

#### ⚡ Утилиты для управления лотами
- **Закрепление лотов**
  - Закрепление важных лотов вверху списка
  - Клиентская сортировка без отправки данных на сервер
  - Сохранение закреплённых лотов между сеансами
  - Визуальный индикатор закреплённых лотов

- **Дублирование лотов**
  - Создание визуальных копий существующих лотов
  - Подтверждение перед дублированием
  - Уведомление об успешном дублировании

- **Массовое управление лотами**
  - Отключение/включение отдельных лотов
  - Массовое отключение всех лотов
  - Массовое включение всех лотов
  - Визуальная индикация отключённых лотов

- **Быстрая жалоба**
  - Мгновенный доступ к форме жалобы
  - Автоматическое заполнение ID лота
  - Открытие формы в новой вкладке

- **Счётчик товаров**
  - Отображение общего количества лотов
  - Подсчёт активных лотов
  - Подсчёт закреплённых лотов
  - Обновление в реальном времени

#### 📊 Панель быстрых действий (Quick Trade Panel)
- Плавающая панель с доступом ко всем утилитам
- Перетаскиваемый интерфейс
- Кнопки массовых операций
- Интегрированный счётчик товаров
- Возможность скрытия панели

#### 🔔 Система уведомлений
- Универсальный менеджер уведомлений
- Поддержка различных типов уведомлений (успех, ошибка, предупреждение, информация)
- Подтверждение для деструктивных операций
- Анимированное появление/исчезновение
- Автоматическое закрытие уведомлений

#### 🛡️ Безопасность и стабильность
- MutationObserver для отслеживания изменений DOM
- Graceful degradation при изменениях разметки FunPay
- Подтверждение перед всеми деструктивными операциями
- Безопасное хранение настроек в локальном хранилище
- Логирование действий пользователя

#### 📱 Интеграция с интерфейсом
- Новый раздел "Утилиты лотов" в popup окне
- Новая вкладка "Утилиты лотов" в расширенных настройках
- Подробное описание всех функций
- Переключатели включения/выключения утилит
- Информационные подсказки

### Изменено
- Обновлён manifest.json для подключения новых модулей
- Расширена структура хранения настроек
- Улучшена система обмена сообщениями между компонентами
- Обновлена документация USAGE.md с разделом об утилитах лотов
