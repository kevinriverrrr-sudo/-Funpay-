# Changelog

Все заметные изменения в проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2024-11-03

### Добавлено

#### Основные функции
- Поддержка смены тем оформления
  - Предустановленная тёмная тема
  - Предустановленная светлая тема
  - Синяя тема
  - Фиолетовая тема
  - Возможность создания пользовательских тем
  - Сохранение настроек тем в локальном хранилище

- Кастомизация обложки
  - Загрузка собственных изображений для фона/обложки сайта
  - Поддержка форматов: JPG, PNG, GIF
  - Настройка позиционирования изображения (центр, верх, низ, углы)
  - Настройка масштабирования изображения (заполнить, вместить, оригинал)
  - Ограничение размера файла до 5 МБ

- Изменение шрифтов
  - Выбор из 12+ популярных шрифтов Google Fonts
  - Настройка размера шрифта (12-20px)
  - Применение шрифтов ко всем элементам сайта
  - Предпросмотр шрифтов в реальном времени

#### Интерфейс
- Popup окно расширения с основными настройками
  - Быстрый выбор темы
  - Быстрый выбор шрифта
  - Настройка размера шрифта
  - Загрузка обложки
  - Кнопки применения и сброса настроек

- Страница расширенных настроек
  - Вкладка "Темы" с визуальным предпросмотром
  - Вкладка "Шрифты" с детальными настройками
  - Вкладка "Обложки" с полным управлением фоном
  - Вкладка "Своя тема" для создания кастомных цветовых схем
  - Предпросмотр изменений в реальном времени

#### Техническая реализация
- Manifest V3 для совместимости с современными браузерами
- Content scripts для внедрения стилей на страницы funpay.com
- Storage API для сохранения пользовательских настроек
- CSS injection для применения кастомных стилей
- Background service worker для фоновых операций
- Обработка и хранение изображений через base64

#### Документация
- Подробный README.md с инструкциями по установке и использованию
- CONTRIBUTING.md с руководством для разработчиков
- USAGE.md с полным руководством пользователя
- LICENSE (MIT)
- CHANGELOG.md для отслеживания версий

#### Ресурсы
- Набор иконок расширения (16x16, 32x32, 48x48, 128x128)
- JSON файл с предустановленными темами
- JSON файл с доступными шрифтами
- Структура для дополнительных ресурсов

### Совместимость
- Chrome 88+
- Edge 88+
- Opera 74+
- Brave (последние версии)
- Firefox 109+ (с ограничениями Manifest V3)

### Известные ограничения
- Размер файла обложки ограничен 5 МБ
- Шрифты загружаются с Google Fonts (требуется интернет)
- Некоторые элементы сайта могут не поддерживать кастомизацию
- В Firefox могут быть небольшие отличия в работе из-за Manifest V3

## [1.1.0] - 2024-11-04

### Добавлено

#### Визуальные эффекты
- **Снежный след курсора**
  - Canvas-анимация с падающими снежинками, следующими за курсором
  - Оптимизация производительности: throttling (16ms), ограничение частиц (50 max)
  - GPU-ускорение через requestAnimationFrame
  - Переключатель включения/отключения в popup и настройках

- **Анимированный логотип FunPay**
  - Замена стандартного логотипа в шапке сайта на анимированный SVG
  - Вращающиеся элементы и пульсация с аппаратным ускорением
  - Встроенная кнопка паузы/возобновления анимации
  - Минимальное влияние на производительность
  - Автоматическое восстановление оригинального логотипа при отключении

- **Пользовательские курсоры**
  - 6 предустановленных стилей (pointer, neonPointer, arrow, target, gaming)
  - Загрузка собственных изображений курсора (PNG, GIF до 1 МБ)
  - CSS-only реализация без JavaScript накладных расходов
  - Автоматические fallback'и для совместимости с браузерами
  - Предпросмотр курсора перед применением

#### Интерфейс
- Новая вкладка "Визуальные эффекты" в расширенных настройках
  - Переключатели для каждого эффекта
  - Подробные описания и предупреждения о производительности
  - Информационные блоки о совместимости и оптимизации
  - Настройки для выбора типа курсора и загрузки изображений

- Секция "Визуальные эффекты" в popup окне
  - Быстрые переключатели для снежного эффекта, логотипа и курсора
  - Стилизованные чекбоксы с иконками
  - Одним кликом можно отключить все эффекты

#### Документация
- Раздел "Визуальные эффекты" в README.md с описанием всех новых функций
- Раздел "Производительность и оптимизация" с техническими деталями
- Новые вопросы в FAQ.md:
  - Как работают визуальные эффекты?
  - Можно ли использовать все эффекты одновременно?
  - Как быстро отключить эффекты?
  - Troubleshooting для визуальных эффектов
- Обновлены рекомендации по производительности

### Технические улучшения
- Три новых модуля: `snow-trail.js`, `animated-logo.js`, `custom-cursor.js`
- Интеграция модулей в основной content script
- Расширение структуры хранилища для новых настроек
- Обновление manifest.json для загрузки новых скриптов
- CSS стили для toggle-переключателей и визуальных эффектов

### Производительность
- Снежный эффект оптимизирован с помощью:
  - Throttling событий мыши (16ms)
  - Ограничение количества частиц (50 max)
  - requestAnimationFrame для плавной анимации
  - Автоматическая очистка устаревших частиц
- Анимированный логотип использует SVG с аппаратным ускорением
- Курсоры применяются через CSS без JavaScript overhead
