# Changelog

Все заметные изменения в проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2024-11-03

### Добавлено

#### Основные функции
- Поддержка смены тем оформления
  - Предустановленная тёмная тема
  - Предустановленная светлая тема
  - Синяя тема
  - Фиолетовая тема
  - Возможность создания пользовательских тем
  - Сохранение настроек тем в локальном хранилище

- Кастомизация обложки
  - Загрузка собственных изображений для фона/обложки сайта
  - Поддержка форматов: JPG, PNG, GIF
  - Настройка позиционирования изображения (центр, верх, низ, углы)
  - Настройка масштабирования изображения (заполнить, вместить, оригинал)
  - Ограничение размера файла до 5 МБ

- Изменение шрифтов
  - Выбор из 12+ популярных шрифтов Google Fonts
  - Настройка размера шрифта (12-20px)
  - Применение шрифтов ко всем элементам сайта
  - Предпросмотр шрифтов в реальном времени

#### Интерфейс
- Popup окно расширения с основными настройками
  - Быстрый выбор темы
  - Быстрый выбор шрифта
  - Настройка размера шрифта
  - Загрузка обложки
  - Кнопки применения и сброса настроек

- Страница расширенных настроек
  - Вкладка "Темы" с визуальным предпросмотром
  - Вкладка "Шрифты" с детальными настройками
  - Вкладка "Обложки" с полным управлением фоном
  - Вкладка "Своя тема" для создания кастомных цветовых схем
  - Предпросмотр изменений в реальном времени

#### Техническая реализация
- Manifest V3 для совместимости с современными браузерами
- Content scripts для внедрения стилей на страницы funpay.com
- Storage API для сохранения пользовательских настроек
- CSS injection для применения кастомных стилей
- Background service worker для фоновых операций
- Обработка и хранение изображений через base64

#### Документация
- Подробный README.md с инструкциями по установке и использованию
- CONTRIBUTING.md с руководством для разработчиков
- USAGE.md с полным руководством пользователя
- LICENSE (MIT)
- CHANGELOG.md для отслеживания версий

#### Ресурсы
- Набор иконок расширения (16x16, 32x32, 48x48, 128x128)
- JSON файл с предустановленными темами
- JSON файл с доступными шрифтами
- Структура для дополнительных ресурсов

### Совместимость
- Chrome 88+
- Edge 88+
- Opera 74+
- Brave (последние версии)
- Firefox 109+ (с ограничениями Manifest V3)

### Известные ограничения
- Размер файла обложки ограничен 5 МБ
- Шрифты загружаются с Google Fonts (требуется интернет)
- Некоторые элементы сайта могут не поддерживать кастомизацию
- В Firefox могут быть небольшие отличия в работе из-за Manifest V3

## [1.1.0] - 2024-11-04

### Добавлено

#### Функции автоматизации
- 🤖 Автоматические ответы на отзывы
  - Настраиваемые шаблоны для разных рейтингов (1-5 звезд)
  - Фильтры по рейтингу и ключевым словам
  - Настраиваемые задержки перед отправкой
  
- 📅 Запланированные сообщения
  - Отложенная отправка (follow-ups)
  - Scheduled delayed responses
  - Автоматическая эскалация необработанных запросов
  - Поддержка chrome.alarms для точного планирования
  
- 🛡️ Правила безопасности
  - Ограничение частоты отправки (rate limiting)
  - Настраиваемые лимиты на контакт
  - Тихие часы (quiet hours) для уважения времени клиентов
  - Ручное управление и отмена сообщений
  
- 📝 Система шаблонов
  - Создание и управление шаблонами сообщений
  - Специализированные шаблоны для отзывов
  - Настройка задержек для каждого шаблона
  - Фильтры и условия применения

- 📊 Мониторинг и статистика
  - Отображение статуса автоматизации в popup
  - Счетчик отправленных сообщений за день
  - Список запланированных сообщений
  - Подробная статистика работы системы

- 💾 Экспорт и импорт настроек
  - Полный экспорт всех настроек в JSON
  - Импорт с выбором компонентов
  - Валидация импортируемых данных
  - Опция очистки существующих настроек

#### Интерфейс
- Новая вкладка "🤖 Автоматизация" в настройках
  - Управление включением/выключением автоматизации
  - Настройка лимитов и ограничений
  - Конфигурация тихих часов
  - Управление шаблонами сообщений и отзывов
  
- Новая вкладка "💾 Экспорт/Импорт"
  - Экспорт настроек в файл
  - Импорт с предпросмотром
  - Выбор компонентов для импорта
  
- Секция автоматизации в popup
  - Отображение статуса (включено/выключено)
  - Статистика отправленных сообщений
  - Количество запланированных сообщений
  - Предпросмотр ближайших отправок

#### Техническая реализация
- Новые модули автоматизации:
  - `autoresponder.js` - менеджер автоответов
  - `review-monitor.js` - отслеживание отзывов
  - `settings-manager.js` - управление настройками
  
- Chrome Alarms API для планирования
- Notifications API для уведомлений
- Расширенный Background Service Worker
- Обновленный Content Script с поддержкой автоотправки

#### Документация
- Новый файл AUTOMATION.md с полным руководством
- Обновлен README.md с описанием автоматизации
- Расширен API.md документацией Automation API
- Обновлены все руководства

#### Разрешения
- Добавлено разрешение `alarms` для планирования
- Добавлено разрешение `notifications` для уведомлений

### Безопасность
- Реализована защита от спама
- Валидация всех импортируемых данных
- Локальное хранение всех данных
- Нет внешних серверов или аналитики
