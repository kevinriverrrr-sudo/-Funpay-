# Быстрый старт FunPay Customizer

Минималистичное руководство для быстрого начала работы.

## 🚀 За 3 шага

### 1️⃣ Установка (2 минуты)

```bash
# Скачайте расширение
git clone https://github.com/yourusername/funpay-customizer.git
cd funpay-customizer
```

Или [скачайте ZIP](https://github.com/yourusername/funpay-customizer/archive/refs/heads/main.zip) и распакуйте.

### 2️⃣ Загрузка в браузер (1 минута)

**Chrome / Edge / Brave:**
1. Откройте `chrome://extensions/` (или `edge://extensions/`)
2. Включите "Режим разработчика" (справа вверху)
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку `funpay-customizer`

**Firefox:**
1. Откройте `about:debugging#/runtime/this-firefox`
2. Нажмите "Загрузить временное дополнение"
3. Выберите файл `manifest.json` из папки

### 3️⃣ Использование (10 секунд)

1. Откройте [FunPay.com](https://funpay.com)
2. Нажмите на иконку расширения 🎨
3. Выберите тему (например, "Тёмная")
4. Нажмите "Применить"

**Готово!** Сайт изменил внешний вид! ✨

## 💡 Что дальше?

### Попробуйте больше функций:

**Изменить шрифт:**
```
Popup → Шрифт → Roboto → Применить
```

**Добавить фон:**
```
Popup → Загрузить изображение → Выбрать файл → Применить
```

**Создать свою тему:**
```
Расширенные настройки → Своя тема → Настроить цвета → Сохранить
```
