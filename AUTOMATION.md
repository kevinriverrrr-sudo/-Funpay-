# Автоматизация лотов - Руководство

## Описание

Функция автоматизации лотов в FunPay Customizer позволяет автоматически поднимать и переключать (активировать/деактивировать) ваши лоты по заданному расписанию.

## Требуемые разрешения

Для работы функции автоматизации расширение запрашивает следующие разрешения:

- **alarms** - для планирования задач по расписанию
- **notifications** - для отображения уведомлений о выполнении задач
- **scripting** - для взаимодействия со страницами FunPay
- **storage** - для сохранения расписаний и настроек
- **activeTab** - для работы с активными вкладками
- **host_permissions** - доступ к funpay.com

## Настройка

### 1. Включение автоматизации

1. Откройте настройки расширения
2. Перейдите на вкладку "Автоматизация"
3. Убедитесь, что переключатель "Автоматизация включена" активен
4. При необходимости включите "Показывать уведомления"

### 2. Создание расписания

1. В разделе "Создать новое расписание" заполните форму:
   - **Название** - понятное имя для расписания (например, "Утреннее поднятие")
   - **Действие** - выберите одно из:
     - Поднять все лоты
     - Активировать все лоты
     - Деактивировать все лоты
   - **Частота** - как часто выполнять действие:
     - Один раз (нужно указать дату и время)
     - Каждые 15/30 минут
     - Каждый 1/2/4/6/12/24 часа

2. Нажмите "Создать расписание"

### 3. Управление расписаниями

Для каждого расписания доступны действия:
- **Приостановить/Возобновить** - временная остановка выполнения
- **Удалить** - полное удаление расписания

## Ручное управление

На вкладке "Лоты" доступны кнопки для ручного выполнения действий:
- ⬆️ **Поднять все лоты** - поднимает все ваши лоты
- ✓ **Активировать все лоты** - включает все лоты
- ✕ **Деактивировать все лоты** - отключает все лоты

## Важные ограничения и рекомендации

### Лимиты FunPay

⚠️ **FunPay устанавливает лимиты на операции с лотами:**

1. **Частота поднятия** - не чаще чем раз в 30-60 минут (зависит от типа аккаунта)
2. **Дневной лимит** - ограниченное количество поднятий в день
3. **Тайм-ауты** - при превышении лимитов возможны временные блокировки

### Рекомендации по использованию

✅ **Безопасные практики:**

- Устанавливайте интервал поднятия **не менее 30 минут**
- Не создавайте более 2-3 одновременных расписаний
- Используйте автоматизацию в разумных пределах
- Регулярно проверяйте результаты выполнения

❌ **Избегайте:**

- Слишком частых поднятий (каждые 15 минут)
- Одновременного создания множества расписаний
- Круглосуточного непрерывного поднятия
- Игнорирования ошибок о превышении лимитов

## Технические детали

### Как это работает

1. **Фоновый процесс** - расширение использует service worker для работы в фоне
2. **Chrome Alarms API** - создает расписания для автоматического выполнения
3. **DOM взаимодействие** - находит и нажимает кнопки на странице FunPay
4. **Retry механизм** - повторяет попытки при временных сбоях
5. **Селекторы** - использует умный поиск элементов для надежности

### Селекторы элементов

Расширение ищет элементы лотов по следующим селекторам:
```javascript
lotList: '.tc-item, .offer-list-item, [class*="lot-"], [class*="offer-"]'
liftButton: '[data-action="raise"], .tc-order-btn-raise, button[title*="поднять"]'
toggleButton: '[data-action="toggle"], .tc-order-btn-toggle'
```

### Механизм повторов

- **Максимум попыток:** 3
- **Задержка между попытками:** 1 секунда
- **Задержка между лотами:** 1 секунда (для избежания rate limits)

## Устранение неполадок

### Автоматизация не работает

1. **Проверьте настройки:**
   - Автоматизация включена?
   - Расписание не приостановлено?

2. **Проверьте вкладки браузера:**
   - Расширение должно быть установлено и активно
   - Рекомендуется иметь открытую вкладку funpay.com

3. **Проверьте консоль:**
   - Откройте DevTools (F12)
   - Посмотрите на ошибки в консоли

### Получаю ошибки о лимитах

1. **Увеличьте интервал** - установите частоту 1-2 часа
2. **Подождите** - дайте аккаунту "отдохнуть" несколько часов
3. **Проверьте FunPay** - возможно есть ограничения на вашем аккаунте

### Лоты не поднимаются

1. **Проверьте структуру страницы** - FunPay мог изменить HTML
2. **Обновите расширение** - возможно вышла новая версия
3. **Сообщите о проблеме** - создайте issue на GitHub

## Edge Cases (Граничные случаи)

### Браузер закрыт
- ⚠️ Алармы Chrome не работают когда браузер полностью закрыт
- Держите браузер открытым для работы автоматизации

### Нет вкладок FunPay
- Расширение автоматически откроет вкладку в фоне
- Может добавить 2-3 секунды к времени выполнения

### Изменения на FunPay
- Расширение использует несколько селекторов для надежности
- При обновлении дизайна FunPay может потребоваться обновление расширения

### Конфликты расписаний
- Если два расписания выполняются одновременно, они будут выполнены последовательно
- Рекомендуется разносить расписания по времени

## Безопасность

### Хранение данных
- Все расписания хранятся локально в chrome.storage.sync
- Данные синхронизируются между устройствами (если включена синхронизация Chrome)
- Расширение не отправляет данные на внешние серверы

### Приватность
- Расширение не собирает личные данные
- Не отслеживает активность пользователя
- Открытый исходный код для аудита
