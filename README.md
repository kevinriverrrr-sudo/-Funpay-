## 🎨 Возможности

### Смена тем оформления
- **Предустановленные темы**: Тёмная, светлая, синяя, фиолетовая
- **Пользовательские темы**: Создавайте свои собственные цветовые схемы
- **Автоматическое сохранение**: Все настройки сохраняются локально

### Кастомизация обложки
- Загрузка собственных изображений для фона сайта
- Поддержка форматов: JPG, PNG, GIF (до 5 МБ)
- Настройка позиционирования и масштабирования изображения

### Изменение шрифтов
- Выбор из популярных шрифтов Google Fonts
- Настройка размера шрифта (12-20px)
- Применение шрифтов ко всем элементам сайта
- Предпросмотр шрифтов в реальном времени

### 🤖 Автоматизация (НОВОЕ!)
- **Автоответы на отзывы**: Автоматические ответы с настраиваемыми фильтрами по рейтингу
- **Запланированные сообщения**: Отправка с задержкой (follow-ups, delayed responses)
- **Эскалация**: Автоматические напоминания о необработанных запросах
- **Шаблоны сообщений**: Создавайте и управляйте шаблонами
- **Безопасность**:
  - Ограничение частоты (rate limiting)
  - Тихие часы (quiet hours)
  - Ручное управление (manual override)
- **Мониторинг**: Статистика и просмотр запланированных сообщений
- **Экспорт/Импорт**: Резервное копирование всех настроек

### Интерфейс управления
- Popup окно с быстрыми настройками и статистикой автоматизации
- Страница расширенных настроек
- Предпросмотр изменений

## 📦 Установка

### Chrome / Edge / Opera / Brave

1. Скачайте или клонируйте этот репозиторий
2. Откройте `chrome://extensions/` в браузере
3. Включите "Режим разработчика" в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с расширением
6. Готово! Иконка расширения появится на панели инструментов

### Firefox

1. Скачайте или клонируйте этот репозиторий
2. Откройте `about:debugging#/runtime/this-firefox`
3. Нажмите "Загрузить временное дополнение"
4. Выберите файл `manifest.json` из папки расширения
5. Готово!

## 🚀 Использование

### Быстрые настройки (Popup)

1. Нажмите на иконку расширения на панели инструментов
2. Выберите тему из выпадающего списка
3. Настройте шрифт и его размер
4. Загрузите обложку (опционально)
5. Нажмите "Применить"

### Расширенные настройки

1. Нажмите на "Расширенные настройки" в popup окне
2. Используйте вкладки для навигации:
   - **Темы**: Выбор предустановленных тем с предпросмотром
   - **Шрифты**: Детальная настройка шрифтов с предпросмотром
   - **Обложки**: Загрузка и настройка фонового изображения
   - **Своя тема**: Создание полностью кастомной темы с помощью цветовой палитры
   - **🤖 Автоматизация**: Настройка автоответов, отслеживания отзывов и правил отправки
   - **💾 Экспорт/Импорт**: Резервное копирование и восстановление настроек

## 🎯 Технические детали

### Технологии
- **Manifest V3** - современный стандарт для расширений
- **Content Scripts** - для внедрения стилей на страницы FunPay
- **Storage API** - для сохранения пользовательских настроек
- **CSS Injection** - для применения кастомных стилей
- **Service Worker** - для фоновых операций
- **Chrome Alarms API** - для планирования автоматических сообщений
- **Notifications API** - для уведомлений об автоматизации

### Совместимость
- ✅ Chrome 88+
- ✅ Edge 88+
- ✅ Opera 74+
- ✅ Brave (любая версия с поддержкой Chromium)
- ⚠️ Firefox 109+ (с некоторыми ограничениями Manifest V3)

## 🔒 Безопасность и конфиденциальность

- Расширение работает только на сайте FunPay.com
- Все настройки хранятся локально в браузере
- Не собирает и не передает никакие данные
- Не требует доступа к личной информации
- Открытый исходный код для проверки
