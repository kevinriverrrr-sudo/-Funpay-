## 📦 Установка

### Chrome / Edge / Opera / Brave

1. Скачайте или клонируйте этот репозиторий
2. Откройте `chrome://extensions/` в браузере
3. Включите "Режим разработчика" в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с расширением
6. Готово! Иконка расширения появится на панели инструментов

### Firefox

1. Скачайте или клонируйте этот репозиторий
2. Откройте `about:debugging#/runtime/this-firefox`
3. Нажмите "Загрузить временное дополнение"
4. Выберите файл `manifest.json` из папки расширения
5. Готово!

## 🚀 Использование

### Dashboard (Быстрая панель)

1. Нажмите на иконку расширения на панели инструментов
2. Увидите компактный Dashboard с:
   - **Быстрые переключатели** - включите нужные функции (Аналитика, Инструменты лотов, Автоответчик, Визуальные эффекты)
   - **Выбор темы** - мгновенно смените тему оформления
   - **Статистика** - количество активных функций и текущая тема
3. Нажмите **"Применить"** для сохранения изменений
4. Кнопка **"Настройки"** открывает Центр управления

### Центр управления (Расширенные настройки)

1. Откройте Центр управления через кнопку "Настройки" в Dashboard
2. Навигация через боковое меню с 10 разделами:
   - 🎨 **Кастомизация** - темы, шрифты, обложки
   - 📊 **Аналитика рынка** - отслеживание цен и анализ
   - 📦 **Управление лотами** - инструменты для лотов
   - 🤖 **Автоматизация** - автоответчик и автообновление
   - 💬 **Чат и сообщения** - улучшения чата
   - 🌐 **Перевод** - автоматический перевод
   - ✨ **Визуальные эффекты** - анимации и стили
   - 🔧 **Утилиты** - дополнительные инструменты
   - 👤 **Аккаунты** - управление аккаунтами
   - ℹ️ **О расширении** - информация и ссылки

3. Настройте нужные параметры в каждом разделе
4. Используйте панель действий внизу:
   - **💾 Сохранить все изменения** - применить настройки
   - **↺ Сбросить раздел** - вернуть к умолчаниям
   - **📤 Экспорт** / **📥 Импорт** - сохранение/загрузка настроек

### Клавиатурные сочетания

В Центре управления:
- `↑` / `↓` - переключение между разделами
- `Home` - первый раздел
- `End` - последний раздел
- `Enter` / `Space` - открыть раздел

## 🎯 Технические детали

### Технологии
- **Manifest V3** - современный стандарт для расширений
- **Content Scripts** - для внедрения стилей на страницы FunPay
- **Storage API** - для сохранения пользовательских настроек
- **CSS Injection** - для применения кастомных стилей
- **Service Worker** - для фоновых операций

### Совместимость
- ✅ Chrome 88+
- ✅ Edge 88+
- ✅ Opera 74+
- ✅ Brave (любая версия с поддержкой Chromium)
- ⚠️ Firefox 109+ (с некоторыми ограничениями Manifest V3)

## 🔒 Безопасность и конфиденциальность

- Расширение работает только на сайте FunPay.com
- Все настройки хранятся локально в браузере
- Не собирает и не передает никакие данные
- Не требует доступа к личной информации
- Открытый исходный код для проверки
