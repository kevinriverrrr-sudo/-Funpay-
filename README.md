- Предпросмотр изменений

## 📦 Установка

### Chrome / Edge / Opera / Brave

1. Скачайте или клонируйте этот репозиторий
2. Откройте `chrome://extensions/` в браузере
3. Включите "Режим разработчика" в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с расширением
6. Готово! Иконка расширения появится на панели инструментов

### Firefox

1. Скачайте или клонируйте этот репозиторий
2. Откройте `about:debugging#/runtime/this-firefox`
3. Нажмите "Загрузить временное дополнение"
4. Выберите файл `manifest.json` из папки расширения
5. Готово!

## 🚀 Использование

### Быстрые настройки (Popup)

1. Нажмите на иконку расширения на панели инструментов
2. Выберите тему из выпадающего списка
3. Настройте шрифт и его размер
4. Загрузите обложку (опционально)
5. Нажмите "Применить"

### Расширенные настройки

1. Нажмите на "Расширенные настройки" в popup окне
2. Используйте вкладки для навигации:
   - **Темы**: Выбор предустановленных тем с предпросмотром
   - **Шрифты**: Детальная настройка шрифтов с предпросмотром
   - **Обложки**: Загрузка и настройка фонового изображения
   - **Своя тема**: Создание полностью кастомной темы с помощью цветовой палитры

## 🛠️ Структура проекта

```
funpay-customizer/
├── manifest.json           # Манифест расширения (Manifest V3)
├── shared/                 # Общие утилиты и константы
│   ├── constants.js       # Константы (MESSAGE_TYPES, STORAGE_KEYS)
│   ├── storage.js         # StorageManager - управление хранилищем
│   ├── messaging.js       # MessageBus - система обмена сообщениями
│   └── dom.js             # DOMHelpers - утилиты для DOM
├── background/            # Background service worker (модульный)
│   ├── index.js          # Главный файл service worker
│   └── modules/          # Модули background worker
│       ├── install.js    # Обработка установки/обновления
│       ├── messaging.js  # Обработчики сообщений
│       ├── storage.js    # Слушатели изменений storage
│       └── migrations.js # Миграции версий хранилища
├── content/               # Content scripts
│   ├── content-new.js    # Логика внедрения стилей (новая архитектура)
│   └── inject.css        # Базовые стили
├── popup/                 # Popup интерфейс
│   ├── popup.html
│   ├── popup-new.js      # Логика popup (использует MessageBus)
│   └── popup.css
├── options/               # Страница расширенных настроек
│   ├── options.html
│   ├── options.js        # Логика настроек (использует MessageBus)
│   └── options.css
├── assets/                # Ресурсы
│   ├── icons/            # Иконки расширения
│   ├── themes/           # Дополнительные темы
│   └── fonts/            # Локальные шрифты
└── README.md             # Документация
```

## 🎯 Технические детали

### Архитектура
- **Модульная MV3 архитектура** - Разделение на независимые модули для лучшей поддерживаемости
- **Versioned Storage Schema** - Система версионирования хранилища с автоматическими миграциями
- **Message Bus** - Унифицированная система обмена сообщениями между компонентами
- **Shared Utilities** - Переиспользуемые утилиты для storage, messaging, и DOM

### Технологии
- **Manifest V3** - современный стандарт для расширений
- **Content Scripts** - для внедрения стилей на страницы FunPay
- **Storage API** - для сохранения пользовательских настроек (sync + local)
- **CSS Injection** - для применения кастомных стилей
- **Service Worker** - модульный background worker для фоновых операций
- **Alarms API** - для планирования автоматических задач (будущая функциональность)

### Совместимость
- ✅ Chrome 88+
- ✅ Edge 88+
- ✅ Opera 74+
- ✅ Brave (любая версия с поддержкой Chromium)
- ⚠️ Firefox 109+ (с некоторыми ограничениями Manifest V3)

## 🔒 Безопасность и конфиденциальность

- Расширение работает только на сайте FunPay.com
- Все настройки хранятся локально в браузере
- Не собирает и не передает никакие данные
- Не требует доступа к личной информации
- Открытый исходный код для проверки

### Разрешения расширения
- **storage** - Хранение пользовательских настроек и профилей
- **activeTab** - Применение стилей к текущей активной вкладке FunPay
- **tabs** - Применение настроек ко всем открытым вкладкам FunPay
- **alarms** - Планирование автоматических действий (будущая функциональность)
- **notifications** - Уведомления о важных событиях (будущая функциональность)
- **contextMenus** - Контекстное меню для быстрого доступа (будущая функциональность)
- **scripting** - Динамическое внедрение функций (будущая функциональность)
